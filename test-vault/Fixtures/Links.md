# Link behavior

## Ordinary targets

- [[Welcome|Return to the start]]
- [[Projects/Amber Lantern#Observations|A heading link]]
- [[Projects/Amber Lantern#^observation-00|A block link]]
- [Relative Markdown link](../Welcome.md)
- [Encoded filename](../Projects/Amber%20Lantern.md)
- [[#Ordinary targets|Same-note heading]]

## Deliberate edge cases

- [[Missing note on purpose]] is an intentionally unresolved link.
- [[Duplicate]] should offer two candidate files.
- [[Fixtures/Unicode – Café|Unicode filename]]

The duplicated basename is a test case, not a data error.
