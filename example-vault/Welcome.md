# Your notes, on your disk

This vault is a folder. Every note is an ordinary Markdown file you can open in another editor.

## Start exploring

Open [[Projects/Field notes|Field notes]] from the outgoing links panel.

Use **Ctrl+S** to save your changes. Open several notes in tabs, or search their contents from the sidebar.

> This is an early Linux prototype. The compatibility roadmap lives in the project documentation.
